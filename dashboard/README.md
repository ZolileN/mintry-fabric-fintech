# Dashboard

This directory contains the Mintry Fabric control plane prototype built as a Next.js App Router application.

## Local launch

```bash
cd dashboard
npm install
npm run dev
```

## Features

- Policy dashboard landing page
- Tailwind CSS styling
- Next.js App Router structure for future metric/detail pages

## Notes

- The dashboard is a front-end scaffold for policy configuration and monitoring.
- Integrate the dashboard with runtime telemetry and policy APIs in Phase 3.
